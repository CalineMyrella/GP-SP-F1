# 🏎️ Desafio Pit Wall - GP de São Paulo 2026

Repositório dedicado ao projeto **Desafio Pit Wall**, uma página web (desktop) com a temática do Grande Prêmio de São Paulo de Fórmula 1. 

Este projeto foi desenvolvido como atividade de fixação das disciplinas de Linguagem de Marcação, focado em estruturação e estilização visual.

# 🏁 Sobre o Projeto
A página reproduz um painel de controle estilo "Pit Wall" contendo informações e interações essenciais da corrida em Interlagos:
- **Grid de Pilotos:** Cards com informações dos pilotos em destaque (Charles Leclerc, Oscar Piastri, George Russell e Gabriel Bortoleto).
- **Classificação:** Tabela de pontuação de pilotos e construtores com opção de busca e filtro.
- **Ingressos:** Formulário completo para reserva de ingressos (Arquibancada A, Setor da Reta, Box VIP), incluindo upload de arquivo (foto para o telão) e campos de dados pessoais.

# 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do formulário, tabelas e seções.
- **CSS3:** Estilização da interface, layout e identidade visual (tema escuro com detalhes em vermelho).

# 📁 Estrutura do Repositório
- `index.html` — Estrutura principal da página.
- `styles.css` — Folha de estilos da aplicação.
- `pit-wall/img/` — Diretório contendo os assets e imagens do projeto.
